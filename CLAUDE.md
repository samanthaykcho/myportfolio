## Performance (Sam noticed lag on 2026-11-26)
- Variable Proximity's per-frame loop reads ALL letter positions first, then writes styles (reading after a write forced a layout per letter: ~400 letters = ~400 layouts/frame). It skips groups on hidden views, off screen, or settled with the cursor far away (`g.settled`; set `g.settled = false` whenever `g.from` changes). Keep that read/write split if you touch it.
- `syncBackground()` pauses the background video on project pages with a `.case-hero` (fully covered) and resumes it before home/about show. The video blur filter is only written when its value changes.
- Measured with puppeteer CDP Performance metrics: kove page script time 329 → 35 ms/s, home layouts 91 → 5 per second while moving the mouse.

## Caching
- GitHub Pages lets browsers cache files for ~10 min, so after a push the new index.html can load with the old style.css (Sam saw the new "download pdf" button unstyled). `style.css` and `script.js` are linked with `?v=YYYYMMDD` — **bump the version in index.html whenever style.css or script.js changes** (add a letter, e.g. `20261127b`, for a second push the same day).
